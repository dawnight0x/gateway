# 升级与回滚

## 支持范围

正式候选版本支持从 `0.8.x`、`0.9.x` 升级。升级会在需要数据库迁移时先创建一致性快照。旧程序不保证能够读取已经由新版本迁移的数据库，因此回滚必须同时恢复升级前的数据快照。

## 便携模式升级

1. 在管理后台执行数据库完整性检查，并创建加密便携备份。
2. 停止网关，确认进程已经退出。
3. 保留原有 `data` 目录，只替换程序、示例配置和文档。
4. 启动新版本，检查 `/health`、`/ready`、版本信息和上游 Key 测试。
5. 保留旧程序和升级前备份，直至完成实际客户端验证。

不要把新版本解压到一个空目录后只复制数据库文件。数据库与 `secret.key` 必须成对保留，否则已加密的上游 Key 无法解密。

## 安装模式升级

安装模式由 `GATEWAY_MODE=installed` 启用。升级程序时保持 `GATEWAY_CONFIG` 与 `GATEWAY_DATA_DIR` 不变。Windows 默认数据目录为 `%LOCALAPPDATA%\LocalAIGateway`；Linux 服务建议使用 `/etc/local-ai-gateway/config.yaml` 和 `/var/lib/local-ai-gateway`。

从旧便携版迁移到安装模式时，先停止旧程序，把完整 `data` 目录复制到新数据目录，再同时设置 `GATEWAY_MODE=installed` 和 `GATEWAY_DATA_DIR`。首次启动后完成完整性检查和 Key 测试，确认无误前不要删除旧目录。

## 回滚

1. 停止新版本。
2. 保存新版本数据副本，便于问题分析。
3. 恢复升级前数据库与对应主密钥，或使用 `gateway-backup restore` 恢复便携备份。
4. 启动旧版本并执行完整性检查。

仅替换可执行文件而继续使用已经迁移的数据不属于受支持的回滚方式。
